# Portfolio Website

A professional portfolio website to showcase your skills, projects, and experience to employers.

## 🌟 Features

- **Responsive Design**: Looks great on desktop, tablet, and mobile devices
- **Modern UI**: Clean and professional design with smooth animations
- **Easy to Customize**: Simple HTML structure that's easy to update with your information
- **Multiple Sections**:
  - Hero section with introduction
  - About section
  - Skills showcase with icons
  - Projects portfolio
  - Experience timeline
  - Contact information

## 🚀 Quick Start

### View Locally

1. Clone this repository
2. Open `index.html` in your web browser

Or use a local server:
```bash
python3 -m http.server 8000
# Then visit http://localhost:8000
```

### Deploy to GitHub Pages

1. Go to your repository settings
2. Navigate to "Pages" section
3. Under "Source", select the branch (usually `main` or `master`)
4. Save and wait a few minutes
5. Your site will be available at `https://dnznCA.github.io/dnznCA/`

## ✏️ Customization

### Update Your Information

Edit `index.html` to personalize:

1. **Hero Section**: Update your name, title, and description
2. **About Section**: Add your personal bio
3. **Skills Section**: List your technical skills
4. **Projects Section**: Showcase your work with descriptions and links
5. **Experience Section**: Add your work history and education
6. **Contact Section**: Update your email, GitHub, and LinkedIn links

### Customize Colors

Edit `style.css` to change the color scheme. The main colors are defined in the `:root` section:

```css
:root {
    --primary-color: #2563eb;
    --secondary-color: #1e40af;
    /* ... other colors */
}
```

## 📱 Responsive Design

The website automatically adapts to different screen sizes:
- Desktop: Full navigation menu and multi-column layouts
- Tablet: Optimized layouts for medium screens
- Mobile: Hamburger menu and single-column layouts

## 🛠️ Technologies Used

- HTML5
- CSS3 (with CSS Grid and Flexbox)
- Vanilla JavaScript
- No external dependencies required
