# Daniel Guo

I build tools for measuring
correlations between macro events, markets, and individual stocks, and
for benchmarking local LLMs. I've also built options pricing from first
principles and robotics perception systems.
### Selected projects

- **[llm-forecasting-calibration-benchmark](https://github.com/dnznCA/llm-forecasting-calibration-benchmark)**
  Scores locally hosted LLMs on forecasting calibration using proper
  scoring rules (Brier, log score), with a Flask dashboard that runs
  benchmark jobs as background subprocesses.

- **[local-llm-council](https://github.com/dnznCA/local-llm-council)**
  CLI that benchmarks local models through Ollama for latency and token
  throughput, with LLM-as-a-judge ranking.

- **[options-lab](https://github.com/dnznCA/options-lab)**
  Options pricing, implied volatility, Monte Carlo, and delta-hedging
  simulation built from first principles, with each result verified by
  an independent check.
